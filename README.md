# Trabalho Avaliativo - Desenvolvimento Web

Trabalho avaliativo da disciplina de Desenvolvimento Web.

## Descrição

Projeto desenvolvido utilizando HTML, CSS e JavaScript.

O JavaScript utiliza a função `getElementById` para realizar uma ação/evento na página.

## Arquivos

- `index.html` — estrutura da página
- `estilo.css` — estilização
- `script.js` — funcionalidades em JavaScript
